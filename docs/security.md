# Security and operational boundaries

The operator uses a dedicated service account. Generated rules read policies, Deployments, HPAs and Secret metadata; update policy status and `/scale`; create/update ownership and election Leases; and emit Events. Helm renders these as a Role in the managed namespace, with a separate election Role in the operator namespace. Cluster-wide mode is explicit. No cluster-admin binding is installed.

Secret watches require namespaced list/watch permission for metadata, and credential collection needs get permission. Kubernetes RBAC cannot constrain a Secret's returned fields: this identity can read Secrets in the watched namespace. Deploy the operator only in trusted namespaces, use scoped Redis ACL credentials, and consider splitting namespace operators/security domains. Secrets never enter specs, Prometheus labels, status or logs. The example contains an endpoint-only Secret, not a production password.

The default replica admission guard is a fail-closed availability dependency for replica-changing Deployment updates in the selected namespace. It permits unrelated workload updates and unmanaged scaling when ownership lookup succeeds. Its service account is the only allowed active-policy replica writer, and a matching intent/conflict check is still required. Pause/delete the policy to deliberately transfer ownership. RBAC protecting policy create/update is therefore a control-plane privilege, not a harmless application permission.

Images use scratch runtimes, non-root UID 65532 and copied CA certificates. Chart Pods drop all capabilities, prohibit privilege escalation, use read-only root filesystems and RuntimeDefault seccomp. Requests/limits, health/readiness checks, an internal metrics Service and NetworkPolicy are included. Default plaintext metrics are restricted to the monitoring namespace by network policy where the CNI enforces it. Kind's default kindnet does **not** enforce NetworkPolicies; use an enforcing CNI for isolation guarantees.

Optional secure metrics use HTTPS and delegated Kubernetes TokenReview/SubjectAccessReview. Configure the scraper's service account token, CA trust and `/metrics` authorization when enabling it; the local monitoring manifest assumes default HTTP. Prometheus's node/proxy permissions are for local monitoring only and broader than the operator's Role. Anonymous Grafana is Viewer-only and local: do not expose it publicly. Production requires authenticated monitoring, appropriate persistent storage, backups, Redis authentication/TLS, image provenance and controlled admission certificate rotation.

OpenTelemetry export is disabled until OTEL_EXPORTER_OTLP_ENDPOINT is configured. The SDK samples 10% of root spans, uses a bounded batch exporter, and does not attach job payloads or Secrets. Use a trusted authenticated OTLP endpoint; exporter connection configuration follows standard OTEL environment variables.

CI runs dependency vulnerability analysis and high/critical container scans, but a past scan is not a permanent security guarantee. See the timestamped verification report for executed results. Release publishing is explicit workflow dispatch with publish=false by default and a configurable GitHub `release` environment protection boundary.
